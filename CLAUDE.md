# apple-tools

CLIs for reading and writing local Apple app data: Notes, Mail, Messages, Phone,
Maps, Reminders, Calendar, Contacts, plus opt-in plugins and a cross-source
index (`apple-index`). Everything runs locally against the user's **real** data.
Every tool is reachable as `apple <tool> …`; `apple --which` shows the binaries.

🛑 **Nothing leaves the machine except three visible, opt-in exceptions:**

1. **Geocoding** — `apple maps geocode`, `reminders --at`, `calendar --at`. It
   lives in its own `Geocoding` target so the dependency stays visible;
   `--local-only` refuses it.
2. **The app's Places map** — MapKit fetches tiles for a region. The user's
   places are never sent. No CLI makes this call.
3. **Plugins** — run only after `apple plugins enable`, and one that connects
   must declare its hosts in its manifest.

Keep it that way: new network use goes in its own target and is opt-in.

## Rules

1. **`--json` for anything you parse.** Plain output is for humans and changes.
2. **Reads are free; writes touch real, synced data.** Confirm with the user
   before any create, edit, complete, move or delete they did not clearly ask
   for. Use `--dry-run` where it exists (`mail move`, `calendar invite`,
   `contacts move/link`) and show the user its output first.
3. **Never edit a note body that has attachments or checklists.** The
   AppleScript body write destroys them, unrecoverably. `notes create/append`
   go through Shortcuts and are safe.
4. **`apple mail` never writes a message body.** `compose/reply/forward` open
   a window and put the body on the pasteboard; the user presses ⌘V and ⌘S.
   Report `awaiting_paste`, never "sent" or "saved". There is no `send`.
5. **Contacts writes sync everywhere with no undo.** On `edit`, `--email`,
   `--url` etc. **replace** every value; use `--add-*` / `--remove-*` to change one.
6. **Calendar invitee changes send real mail.** `invite --dry-run` first.
   `phone dial` places a real call; the user clicks the confirmation.
7. **IDs are per-tool.** Reminder indexes shift — re-run `show` right before
   acting on one. A recurring event's id is the series: pass `--occurrence` or
   `--series`.
8. **Search before you write.** List, calendar, account and mailbox names must
   match existing ones.
9. **Prove a write by reading it back.** An exit code of 0 from Shortcuts,
   EventKit or AppleScript proves nothing on its own.

## Permissions

Start every access failure with `apple status` (`--json` for detail). It never
prompts. The user must approve grants in their own terminal; an agent cannot.

- **reminders, calendar, contacts** disclaim: the grant belongs to the binary
  and works from any terminal. Never suggest switching terminals for these.
- **mail, messages, phone, maps, notes** read stores under Full Disk Access of
  the *calling terminal*. Mail's compose and `move` also need Automation → Mail.
- macOS prompts only from `notDetermined`. Calendar `writeOnly` looks granted
  and cannot read. The fix is a toggle in System Settings, never a retry.
- `mail_app.probe_killed: true` or `osascript` exit 143 under cmux means cmux
  killed it, not that Mail is wedged. See [`docs/apple-mail.md`](docs/apple-mail.md).

## Plugins

A plugin is an executable `apple-plugin-<name>` in `plugins/<name>/`, Python
stdlib only. **Found is not enabled; only enabled runs** (`apple plugins list`,
`enable`, `config`). Secrets go to the Keychain, never to `plugins.json`.
Nothing in this repo enables a plugin.

## Layout

- `bin/apple` — dispatcher; `bin/apple-plugins` — plugin manager.
- `swift/` — one package, seven binaries. Store readers live in `*Library`
  targets so tests run against a synthetic store. `Geocoding` is the only target
  that touches the network. `ReminderKitBridge` and
  `AppleCalendar/Attendees.swift` use private API resolved at runtime.
- `notes/` — `apple-notes`, the one Python tool (stdlib, system `python3`).
- `plugins/` — dawarich, health (plus `ios/`, the iPhone app), whatsapp.
- `lab/` — `apple-index`, its Swift embedder and PDF reader (`lab/vec/`).
  `lab/emoji-versions.txt` is GENERATED by `lab/emoji-versions`.
- `app/` — `AppleTools.app`, which holds the grants and refreshes the index.
- `util/` — probes that exit 0 when an Apple API surface changes.
- `VERSION` — CalVer `YY.MMDD.Patch`. Change it only with `make set-version` /
  `make bump`; every tool must report the same `--version`.

## Building and testing

`make build | install | check | test | bump | dist`. `make test` is offline.

**Iterate with `make dev && eval "$(make -s dev-path)"`.** It shades mail,
notes, messages, phone and maps only. Reminders, calendar and contacts bind
their TCC grant to the binary path, so a debug build re-prompts; opt in with
`make dev DEV_TOOLS="apple-contacts"`. `make dev-off` undoes it.

The live suites use real data and are gated:

- `notes/run-tests` creates real iCloud notes prefixed `__claude_notes_test__`.
  Do not run it casually.
- `./tests/run-tests [--backends] [--contacts]` drives real calendars and
  contacts. Contacts fixtures match the **exact** first name
  `__claude_contacts_test__`; never loosen that to a prefix.
- `test_mail_wedge.py` is read-only and always runs. **Run it twice**, with
  Mail.app open and closed; each half skips in the other state.
- `APPLE_MAIL_BIN` / `APPLE_CONTACTS_BIN` pick a build. TCC grants are per
  path, so an unapproved binary hangs instead of failing.

🛑 **Never script Mail's composer to test it** — it wedges Mail. Drive it by hand
and measure the `.emlx` against a hand-typed control
([`docs/apple-mail-drafts.md`](docs/apple-mail-drafts.md)).

🛑 **The index holds the plaintext of every email.** Never copy `apple-index`
results anywhere that leaves the machine.
